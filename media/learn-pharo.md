# Learn Pharo

**Learn Pharo** opens the lessons of Professor Stef, the Pharo syntax tutorial of your image, in the **Learn Pharo** page of the playground.

- **Do it** runs a block of code, **Print it** shows its result after it, **Inspect it** opens the result in the inspector.
- Variables you assign in the page are kept between evaluations.
- `ProfStef next.`, `ProfStef previous.` and `ProfStef go.` move between lessons, as in Pharo. The first line of the page has **Previous Lesson**, **Next Lesson** and **Restart**.
- What the code writes on the Transcript appears in the **Pharo Transcript** output.

Each lesson replaces the text of the page: keep the code you want in another playground page (**Pharo: New Playground**).

Run **Pharo: Learn Pharo** from the Command Palette to come back to the lesson where you left it.
